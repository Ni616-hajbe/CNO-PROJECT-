# CNO Project

A simple and responsive web application built using **HTML and CSS**, containerized with **Docker**, and deployed locally on **Kubernetes using Minikube and kubectl**.

## 🚀 Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive design
- **Docker** – Containerization of the web application
- **Kubernetes** – Container orchestration
- **Minikube** – Local Kubernetes cluster
- **kubectl** – Kubernetes cluster management

## 📁 Project Overview

This project demonstrates how to build a simple frontend website and deploy it using containerization and Kubernetes.

The application is packaged into a Docker image and deployed inside a local Kubernetes cluster using Minikube.

## ⚙️ Project Workflow

1. Develop the website using HTML and CSS.
2. Create a Dockerfile to containerize the application.
3. Build a Docker image.
4. Start a local Kubernetes cluster using Minikube.
5. Deploy the application using Kubernetes manifests.
6. Manage and access the application using kubectl.

## 🐳 Docker Commands

```bash
docker build -t cno-project .
```

```bash
docker images
```

## ☸️ Kubernetes Commands

```bash
minikube start
```

```bash
kubectl get nodes
```

```bash
kubectl get pods
```

```bash
kubectl get services
```

## 🌐 Deployment

The application can be deployed locally using Docker and Minikube.

The frontend source code can also be published publicly using GitHub Pages.
